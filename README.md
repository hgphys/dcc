# データ収集とクリーニング

金沢学院大学 情報工学部情報工学科「データ収集とクリーニング」（担当: 後藤 弘光）の演習教材リポジトリです。本講義は、データサイエンスの実務で最も時間を要するデータの収集・前処理工程を、現実的な題材を通じて体験することを目的とします。

対象: 情報工学部情報工学科 2 年次（後期）

---

## 授業概要

データ分析の前段階として不可欠な、データの収集・整形・クリーニングの工程を学ぶ。テキストデータの正規化・形態素解析・ベクトル化、Web スクレイピング、公開データや API の活用、表形式データの探索的分析、欠損値・外れ値処理、抽出・集計・結合、時刻データの扱い、ビニング・エンコーディング・スケーリングなど、実務で頻出する処理を Python （`pandas` 等）で実践する。後半の実践演習では、グループ議論の音声データ（Hylable Discussion）を題材に、データ収集から前処理・分析・レポーティングまでの一連のワークフローを体験する。

## 到達目標

- データ収集・前処理・クリーニングの各工程を理解し、目的に応じて適切な処理を選択できる
- Python のデータ処理ライブラリ（`pandas` など）を用いて表形式データを加工できる
- 実際のデータに潜むノイズや欠損・不整合を自力で発見し、対処できる

### 実践演習について

第13, 14回では、実際のグループ議論データを題材に、データ収集から分析レポート作成までの一連の流れを体験します。

- **題材**: 受講者自身のグループ議論を [Hylable Discussion 対面版](https://hylable.com/products/) のたまご型レコーダーで録音し、話者分離・自動文字起こしによって話者識別付きの時系列テキストデータ（ASR 出力）として取得します
- **分析**: 座席と学籍番号をアンケートで別途取得し、ASR データと突合することで、「自分がグループ内で何秒発話したか」を定量的に算出します
- **データの取り扱い**: 録音および収録データの受講生への配布は、事前に受講生本人の同意を得たうえで実施します
- **レポート作成**: 分析結果を Jupyter Notebook 上のレポートとしてまとめます

`dcc_13-14_A_学籍番号.ipynb` が共通課題のテンプレートです。各自の学籍番号に差し替えて提出します。第8回から第12回の演習は、Hylable の ASR 出力に近い形式の共通のサンプルデータを用いて、実践演習に必要なデータの前処理を身に付けます。

この必須課題（A）に加え、年度によって発展的な課題を追加で提示します。例えば 2025 年度は、受講者の性格特性アンケート結果と発話特徴量の関係性を分析する課題を発展課題として実施しました。

## 環境構築（初回のみ）

### 1. Anaconda のインストール

以下のサイトを参考にインストールしてください。

- [Python 環境構築ガイド](https://www.python.jp/install/install.html)
- [Anaconda](https://www.anaconda.com/products/distribution)

> ユーザ名が日本語の場合、インストール先のパスに注意してください。

### 2. 仮想環境の作成

```bash
conda create -n dcc_env python=3.11 -y
```

### 3. 仮想環境の有効化

```bash
conda activate dcc_env
```

プロンプトに `(dcc_env)` と表示されれば OK です。

### 4. 必要パッケージのインストール

```bash
pip install -r requirements.txt
```

## 課題の取り組み方

各回のフォルダには以下のファイルが含まれます。

```
dcc_XX/
├── dcc_XX.ipynb       # 課題本体（Jupyter Notebook）
├── dcc_XX_YY.py       # （一部の回）誤りを含む .py スクリプト
└── data_XX/           # データファイル（ある場合）
```

### 手順

1. **仮想環境を有効化する**

    ```bash
    conda activate dcc_env
    ```

2. **JupyterLab を起動する**

    ```bash
    jupyter lab
    ```

3. **課題に取り組む** — ノートブックを開き、指示に従ってコードを記述・実行します。`.py` スクリプトが併設されている回では、スクリプトの誤りを発見して修正してください。

4. **回答を提出する** — Moodle コースの小テストに回答します。

5. **作業を終えたら無効化する**

    ```bash
    conda deactivate
    ```
